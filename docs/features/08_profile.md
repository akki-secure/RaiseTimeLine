# 機能別要件定義書：プロフィール機能

[← 機能一覧に戻る](../features.md)

## 概要

ユーザーが自分のプロフィール（アイコン画像・表示名・自己紹介）を編集できる機能。また、自分・他ユーザーのプロフィール画面でアイコン・表示名・@ユーザー名・自己紹介を閲覧できる。アイコン画像はAWS S3に保存し、そのURLを`users.avatar_url`に保持する（[aws.md](../aws.md)参照）。

## 詳細仕様

### ユースケース1: プロフィールの閲覧

1. マイページ画面（自分）・他ユーザープロフィール画面（他人）で、アイコン・表示名・@ユーザー名・自己紹介を表示する
2. アイコン未設定（`avatar_url`がNULL）の場合はデフォルトアイコンを表示する
3. 自己紹介未設定（`bio`がNULL）の場合は自己紹介欄を表示しない

### ユースケース2: プロフィールの編集

1. マイページ画面の「プロフィールを編集」ボタンからプロフィール編集画面に遷移する
2. アイコン画像・表示名・自己紹介を編集できる（ユーザー名・メールアドレスは編集不可）
3. アイコン画像は選択直後にクライアント側でプレビュー表示する
4. 保存ボタン押下時、変更内容をサーバーに送信する
5. サーバーはアイコン画像が変更されている場合のみS3にアップロードし、発行されたURLを`users.avatar_url`に保存する。表示名・自己紹介は`users.display_name` / `users.bio`を更新する
6. アイコン画像のアップロードに失敗した場合は保存全体をエラーとし、表示名・自己紹介の変更も反映しない
7. 保存成功後はマイページ画面に戻り、更新後の内容を表示する

## 権限

- プロフィール閲覧: ログイン済み全ユーザー（自分・他人問わず誰でも閲覧可能）
- プロフィール編集: ログイン済みユーザー本人のみ（他ユーザーのプロフィールは編集不可）

## 入出力・バリデーション

| 項目 | バリデーション |
|---|---|
| 表示名 | 1〜50文字、必須 |
| 自己紹介 | 0〜160文字、任意 |
| アイコン画像ファイル形式 | JPEG / PNG / GIF のみ |
| アイコン画像ファイルサイズ | 5MB以下 |
