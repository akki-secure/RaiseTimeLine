# 機能別要件定義書：コメント機能

[← 機能一覧に戻る](../features.md)

## 概要

投稿に対して、投稿者本人だけでなく第三者を含む任意のログイン済みユーザーがコメントできる。各投稿のコメント数を集計し、タイムライン・投稿詳細画面に表示する。

## 詳細仕様

### ユースケース1: コメント投稿

1. 投稿詳細画面でコメント本文（最大140文字）を入力し送信する
2. `comments`テーブルに`post_id`・`user_id`（コメント投稿者、投稿者本人と異なってよい）・本文を保存する
3. 保存成功後、コメント一覧の末尾（または新着順の先頭）に表示する

### ユースケース2: コメント一覧表示

1. 投稿詳細画面を開くと、その投稿に紐づく全コメントを`created_at`の古い順（会話として読める順）で表示する
2. 各コメントにはコメント投稿者のアイコン・表示名・@ユーザー名・投稿日時・本文を表示する

### ユースケース3: コメント数の表示

1. タイムライン・投稿詳細画面の各投稿に、その投稿に紐づく`comments`件数を表示する
2. 件数は`SELECT COUNT(*) FROM comments WHERE post_id = ?`で取得する（[er.md](../er.md#集計方針いいね数コメント数フォロー数)参照）

### ユースケース4: コメント削除

1. 自分が投稿したコメントにのみ削除ボタンを表示する
2. 削除確認後、`comments`テーブルから該当レコードを削除する

## 権限

- コメント投稿: ログイン済み全ユーザー（投稿者本人・第三者どちらも可）
- コメント削除: コメント投稿者本人のみ（投稿の所有者であってもコメント削除はできない）

## 入出力・バリデーション

| 項目 | バリデーション |
|---|---|
| コメント本文 | 必須、1〜140文字 |
