# 機能別要件定義書：ユーザー検索機能

[← 機能一覧に戻る](../features.md)

## 概要

ユーザー名（@handle）または表示名の部分一致検索により、他のユーザーを見つけられる機能。検索結果からプロフィール画面への遷移、その場でのフォローが可能。フォロー機能（[06_follow.md](./06_follow.md)）への主要な導線となる。

## 詳細仕様

### ユースケース1: ユーザー検索

1. ヘッダーの検索アイコンからユーザー検索画面を開く
2. 検索キーワードを入力する（リアルタイム検索、またはEnter/検索ボタンで実行）
3. `username`または`display_name`に対してキーワードの部分一致（`ILIKE '%keyword%'`）検索を行う
4. 一致するユーザーをアイコン・表示名・@ユーザー名・フォロー状態とともに一覧表示する

### ユースケース2: 検索結果からのフォロー

1. 検索結果一覧の各ユーザー行に「フォローする」/「フォロー中」ボタンを表示する
2. ボタン押下でフォロー・フォロー解除を実行する（[06_follow.md](./06_follow.md)のユースケース1・2と同じ処理）

### ユースケース3: 検索結果からプロフィールへ遷移

1. 検索結果のユーザー行（ボタン以外の領域）をクリックすると、そのユーザーのプロフィール画面に遷移する

## 権限

- ユーザー検索: ログイン済み全ユーザー（全ユーザーが検索対象。非公開アカウントの概念は今回のスコープでは持たない）

## 入出力・バリデーション

| 項目 | バリデーション |
|---|---|
| 検索キーワード | 1〜50文字。空欄の場合は検索を実行しない |

## 検索対象外

- 自分自身は検索結果に含めない（アプリ側でフィルタ）
