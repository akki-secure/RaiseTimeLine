# 機能別要件定義書：いいね機能

[← 機能一覧に戻る](../features.md)

## 概要

投稿に対して、投稿者本人だけでなく第三者を含む任意のログイン済みユーザーがいいねできる。1ユーザー1投稿につき1回までとし、各投稿のいいね数を集計・表示する。

## 詳細仕様

### ユースケース1: いいねする

1. タイムライン・投稿詳細画面のいいねボタン（♡アイコン）を押下する
2. 既にいいね済みでなければ`likes`テーブルに`post_id`・`user_id`のレコードを作成する
3. いいねボタンの表示を塗りつぶし（❤️）に変更し、いいね数を+1して表示する

### ユースケース2: いいねを取り消す

1. いいね済みの状態でいいねボタンを再度押下する
2. `likes`テーブルから該当レコード（`post_id`・`user_id`が一致するもの）を削除する
3. いいねボタンの表示を未いいね（♡）に戻し、いいね数を-1して表示する

### ユースケース3: いいね数の表示

1. タイムライン・投稿詳細画面の各投稿に、その投稿に紐づく`likes`件数を表示する
2. 件数は`SELECT COUNT(*) FROM likes WHERE post_id = ?`で取得する（[er.md](../er.md#集計方針いいね数コメント数フォロー数)参照）

### ユースケース4: 二重いいねの防止

1. `likes`テーブルに`UNIQUE (post_id, user_id)`制約を設け、同一ユーザーが同一投稿に複数回いいねできないようにする
2. アプリ側でもいいね済みか判定してボタンの状態を切り替える（表示上の二重送信防止）

## 権限

- いいね・いいね取り消し: ログイン済み全ユーザー（投稿者本人・第三者どちらも可）
- いいねの削除は自分がしたいいねのみ取り消し可能（他人のいいねを取り消すことはできない）

## 入出力・バリデーション

| 項目 | バリデーション |
|---|---|
| 対象投稿 | 存在する投稿であること |
| 二重いいね | DBのユニーク制約で禁止 |
