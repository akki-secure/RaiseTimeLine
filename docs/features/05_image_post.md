# 機能別要件定義書：画像投稿機能

[← 機能一覧に戻る](../features.md)

## 概要

投稿作成時に画像を1枚添付できる。画像はAWS S3に保存し、そのURLを`posts.image_url`に保持する（[aws.md](../aws.md)参照）。

## 詳細仕様

### ユースケース1: 画像添付投稿

1. 投稿フォームで「画像を選択」ボタンから端末内の画像ファイルを選択する
2. 選択直後にクライアント側でプレビュー表示する
3. 投稿ボタン押下時、テキストと画像をあわせてサーバーに送信する
4. サーバーは画像をS3にアップロードし、発行されたURLを`posts.image_url`に保存する
5. 画像アップロードに失敗した場合は投稿全体をエラーとし、テキストのみの投稿は作成しない

### ユースケース2: 画像表示

1. タイムライン・投稿詳細画面で、`image_url`が設定されている投稿は本文の下に画像を表示する
2. `image_url`が未設定の投稿は画像領域を表示しない

## 権限

- 画像添付投稿: ログイン済み全ユーザー（自分の投稿にのみ添付可能）

## 入出力・バリデーション

| 項目 | バリデーション |
|---|---|
| ファイル形式 | JPEG / PNG / GIF のみ |
| ファイルサイズ | 5MB以下 |
| 添付枚数 | 1投稿につき1枚まで |
